## 1. 프로젝트 개요

### 1.1 목적

Claude Code 등의 AI 에이전트가 Model Context Protocol(MCP)을 통해 언리얼 에디터에 접속하여, **JSON 명세를 기반으로 실제 UMG 위젯 블루프린트(.uasset)를 생성, 편집, 저장**하는 시스템을 개발한다.

### 1.2 주요 기능

- AI 에이전트의 UI 레이아웃 제안을 실제 `.uasset` 파일로 물리적 생성
- **에디터 타임(Editor-Time)** 자동화 (런타임 생성이 아님)
- CanvasPanel, GridPanel 등 컨테이너 및 기본 위젯(Button, Text 등) 생성
- 계층 구조(Hierarchy) 자동 구성 및 슬롯(Slot) 속성 제어
- 리플렉션(Reflection)을 이용한 위젯 속성 자동 매핑
- **JSON 기반 UI 스키마 정의 및 파싱**
- **C++ 기반 베이스 클래스 연결을 통한 이벤트 로직 위임**

### 1.3 기대 효과

- UI 프로토타이핑 속도의 비약적 향상
- 반복적인 위젯 배치 및 속성 설정 작업 자동화
- AI가 제안한 디자인을 즉시 엔진 내에서 시각화 및 편집 가능
- 프로그래머-AI 협업을 통한 빠른 UI 이터레이션

## 2. 시스템 요구사항

### 2.1 기능적 요구사항

#### FR-001: 에셋 관리
| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-001-1 | 신규 위젯 블루프린트 생성 (경로 지정) | 필수 |
| FR-001-2 | 기존 위젯 블루프린트 로드 및 편집 | 필수 |
| FR-001-3 | 블루프린트 컴파일 및 저장 | 필수 |
| FR-001-4 | 부모 클래스(Parent Class) 지정 생성 | 필수 |

#### FR-002: 위젯 생성 및 계층 구조
| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-002-1 | Root 위젯 설정 | 필수 |
| FR-002-2 | 컨테이너 위젯(Panel) 생성 및 자식 추가 | 필수 |
| FR-002-3 | 일반 위젯(Control) 생성 | 필수 |
| FR-002-4 | 위젯 이름(Variable Name) 지정 | 필수 |
| FR-002-5 | 기존 위젯 트리 삭제/재구성 | 선택 |

#### FR-003: 속성(Property) 제어
| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-003-1 | 기본 타입(Bool, Int, Float) 속성 설정 | 필수 |
| FR-003-2 | 문자열/텍스트(String, Text) 속성 설정 | 필수 |
| FR-003-3 | 구조체(Color, Vector2D, Margin) 속성 설정 | 필수 |
| FR-003-4 | Enum 타입(Visibility, BrushDrawType) 속성 설정 | 필수 |
| FR-003-5 | 리플렉션을 통한 범용 속성 매핑 | 필수 |

#### FR-004: 슬롯(Slot) 제어
| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-004-1 | CanvasSlot: Anchors, Offsets, Alignment 설정 | 필수 |
| FR-004-2 | Vertical/HorizontalSlot: Padding, Size(Fill/Auto), Alignment | 필수 |
| FR-004-3 | GridSlot: Row, Column, RowSpan, ColumnSpan | 필수 |
| FR-004-4 | OverlaySlot: Horizontal/Vertical Alignment | 선택 |

#### FR-005: 상태 조회
| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-005-1 | 특정 에셋의 위젯 트리 구조 조회 (JSON 반환) | 필수 |
| FR-005-2 | 특정 위젯의 현재 속성 값 조회 | 필수 |
| FR-005-3 | 에셋 존재 여부 확인 | 필수 |

#### FR-006: JSON 스키마 처리
| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-006-1 | 중첩된 JSON 구조 파싱 및 재귀적 위젯 생성 | 필수 |
| FR-006-2 | 유효하지 않은 위젯 타입/속성명에 대한 에러 처리 | 필수 |
| FR-006-3 | 템플릿/프리셋 JSON 로드 및 적용 | 선택 |
